# Limited-capacity-Vehicle-Routing-Problem
### A project aiming to find near-optimal solutions to instances of Limited capacity Vehicle Rounting Problem using Genetic Algorithm.

Note that this project isn't perfectly optimised algorithm-wise, as its point was to write efficient code and learn effective programming techniques.

### How to use:
 - All cpp and hpp files need to be opened as a project in any c++ editor.
 - In the file main.cpp, in line 15, select the problem from the data by changing the folder name and instance name to the ones of specific problem instance ( for example("Vrp-Set-X", "X-n209-k16") opens the problem from "data\lcvrp\Vrp-Set-X\X-n209-k16.lcvrp" )
